# Note kind check chart

This synthetic, silent TJA plays every note kind once so their animations, Don
reactions and sounds can be checked: Don and Ka, big Don and big Ka, hand Don
and hand Ka (drawn with feet when two players play), roll, big roll, a balloon
to pop, a balloon to miss, a kusudama to pop and a kusudama to miss. The whole
sequence then repeats inside Go-Go time.

Every course (Easy to Oni) holds the same notes, so two players can pick any
pair. Balloon and kusudama quotas alternate 3 (pop it) and 99 (let it expire).
Each measure lasts two seconds.

Install it with the other test charts in the custom-song folder of the game
data, for example `USRDIR/custom_songs/Test Charts/Note Kind Check/`, copying
both files. Duet (two-player) charts only exist in the game's own songs; TJA
has none.
